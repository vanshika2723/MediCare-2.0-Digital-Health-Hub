🏥 MediCare 2.0 — Digital Health Hub

MediCare 2.0 is a modern and responsive Digital Healthcare Platform built using HTML, CSS, and JavaScript. It provides an interactive healthcare experience where users can explore doctors, search specialists, book appointments, manage visits, and access smart healthcare features.
