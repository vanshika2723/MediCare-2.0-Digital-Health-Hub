# 🏥 MediCare 2.0 — Digital Health Hub

MediCare 2.0 is a modern and responsive Digital Healthcare Platform built using HTML, CSS, and JavaScript.

The platform provides an interactive healthcare experience where users can explore doctors, search specialists, book appointments, manage visits, and access smart healthcare features.

## ✨ Features

• Doctor Directory
  - Browse specialist doctors
  - View department and qualification
  - Check consultation fee and availability
  - View profile and booking options

• Doctor Search & Filter
  - Search doctors by name or specialty
  - Filter doctors by specialization

• Appointment Booking
  - Select department
  - Select doctor
  - Choose appointment date
  - Select consultation time
  - Enter patient details
  - Confirm appointment

• My Visits
  - View booked appointments
  - Check appointment status
  - View date and time
  - Reschedule appointments
  - Cancel appointments

• AI Quick Care
  - Interactive healthcare guidance
  - Demo-based department routing
  - Quick access to care options

• Care Concierge
  - Helps users navigate healthcare departments
  - Suggests suitable specialists based on selections

• Health Packages
  - Healthcare package cards
  - Service information
  - Package highlights

• Health Dashboard
  - Health-related information
  - Quick-access healthcare cards

• FAQ Section
  - Common healthcare questions
  - Interactive FAQ interface

• Dark Mode
  - Light and dark theme support

• Responsive Design
  - Desktop
  - Tablet
  - Mobile

• LocalStorage
  - Appointment data is stored in the browser
  - Data remains available after refreshing the page

## 🚀 How to Run

1. Download or clone the repository.

2. Open the project folder in VS Code.

3. Open index.html in your browser.

4. You can also use the Live Server extension in VS Code.
